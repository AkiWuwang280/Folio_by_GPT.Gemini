# 页序 · Folio

**一套以阅读体验为核心的 SillyTavern UI 主题与配套扩展。**

把聊天排成一页舒展、清晰的文字。Folio 在保留原主题阅读气质的基础上，进一步整理了界面布局、配色、字体、背景与细节交互，并提供可独立调整的设置面板。

> 当前版本：**1.4.2**

## 功能一览

### 阅读与排版
- 延续原主题的杂志式访谈排版，以清晰的正文层级、舒展留白和细线装饰营造阅读感。
- 支持消息页码、首条消息扉页留白和消息分隔线的独立开关。
- 可调整正文字号比例、行高、每行字数上限与段落间距。
- 角色正文与玩家正文可分别选择字体。
- 针对桌面与窄屏设备保留不同的头像尺寸、消息留白和间距参数，并持续优化正文版心。

### 配色与背景
- 内置五套配色：**墨夜、暖纸、雾青、樱笺、紫宸**。
- 配色与背景图片相互独立，可自由组合。
- 支持填写公开可访问的背景图片 URL，并调整背景遮罩强度。
- 主题颜色通过 SillyTavern 的 SmartTheme 变量适配界面、正文、面板与文字层级。

### MEMENTO 几何暗纹
- 提供低存在感的几何线条暗纹，可单独开关并调整透明度。
- 暗纹中的 **M 代表 “My”**，表达每位使用者自己的阅读空间；它是面向所有使用者的视觉概念，不指向特定个人。

### 界面细节
- 顶部九个导航入口采用统一网格布局，并为底部常用操作配套定制图标。
- 图标会针对浅色界面进行适配。
- 设置面板采用 SillyTavern 原生可折叠抽屉，各功能分组可分别展开或收起。
- 统一抽屉、弹窗、角色卡片与输入区域的边线和视觉细节。
- 优化世界书与预设条目的启用、禁用状态辨识。

## 安装

### 1. 安装扩展

在 SillyTavern 中打开 **扩展 → 安装扩展**，粘贴本仓库地址：

`https://github.com/AkiWuwang280/Folio_by_GPT.Gemini`

仓库默认分支为稳定版，无需额外填写分支名。

### 2. 导入 UI 主题

扩展与 SillyTavern 的 UI 主题 JSON 属于两套独立机制，因此首次使用还需要导入主题文件：

1. 打开 **用户设置 → UI 主题 → 导入主题文件**。
2. 选择本仓库中的 `folio-theme.json`。
3. 在 UI 主题列表中启用导入后的 Folio 主题。

主题文件直链：

[`folio-theme.json`](https://raw.githubusercontent.com/AkiWuwang280/Folio_by_GPT.Gemini/main/folio-theme.json)

### 3. 调整设置

安装并启用后，在 **扩展设置 → 页序 · Folio** 中调整配色、背景、字体、排版和消息版式。大部分设置会自动保存。

## 设计说明

- **主题 JSON** 负责基础 UI 主题与原主题样式。
- **Folio 扩展** 负责额外设置、配色变量、背景控制、MEMENTO 暗纹及补充界面样式。
- 两者配合使用，才能获得完整体验。
- 桌面端与手机端会采用不同的阅读间距参数；不同酒馆版本、第三方整合包或其他扩展可能存在样式兼容差异。
